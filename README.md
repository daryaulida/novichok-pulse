# Пульс новичка

Ранние сигналы ухода новичков в первые 90 дней и задача руководителю в Битрикс24 в один клик.

**Для кого:** HR (видит всех новичков сразу) и руководители подразделений (получают задачу «поговорить» в Битрикс24). Новичок только отвечает на опрос с телефона за минуту.

## Как работает

1. Новичок получает личную ссылку или QR на 3-й, 14-й, 30-й и 60-й день → 4 вопроса: понятны ли задачи, есть ли к кому обратиться, подходит ли график, видит ли себя в компании через месяц.
2. Пульт пересчитывает риск по прозрачным правилам (см. `about.php`) и показывает блок «Поговорить сегодня».
3. Кнопка «Задача в Битрикс24» → `tasks.task.add` через входящий вебхук: ответственный — руководитель, срок — завтра, в описании причины и что спросить.
4. Руководитель отмечает итог разговора → комментарий в задачу и `tasks.task.complete`, риск снижается.

## Стек

PHP 8.1+, SQLite (PDO), обычные HTML/CSS/JS, Chart.js и qrcodejs с cdnjs. Без сборки — работает на любом PHP-хостинге.

## Запуск

```bash
cp config.sample.php config.php   # вписать base_url и вебхук Б24 (права: task, user)
php -S 127.0.0.1:8080
```

База и демо-данные (40 новичков + история за год, люди выдуманные) создаются при первом открытии. Сброс — на странице «Как считается риск» (ключ из `demo_reset_key`).

## Файлы

| Файл | Что делает |
|---|---|
| `lib.php` | БД, демо-данные, расчёт риска, вызовы Битрикс24 |
| `index.php` | Пульт HR |
| `person.php` | Карточка новичка: шкала 90 дней, причины риска, история, действия |
| `q.php` | Опрос новичка (телефон) |
| `links.php` | Кому пора отправить опрос, QR и готовый текст для Viber |
| `api.php` | Действия: задача в Б24, разговор, наставник, сброс демо |
